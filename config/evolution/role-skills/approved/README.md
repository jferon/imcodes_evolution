# Approved Evolution Role Skill Library

Place reviewed role skill Markdown files here to seed future Evolution runs before project-local `.imc/skills/evolution/*.md` files exist.

Rules:

- File name must match the role skill name, for example `product-prd.md` or `visual-hifi.md`.
- Frontmatter must keep `category: evolution` and the matching `name`.
- Project-local `.imc/skills/evolution/<skill>.md` files always win and are never overwritten.
- War Room edits create run-local release candidates under `.imc/evolution/<runId>/skills/release-candidates/`.
- Prefer approving candidates from War Room. Approval strips the candidate governance footer, writes `<skill>.md`, and appends a versioned audit entry to `manifest.json`.
- `manifest.json` is generated by the daemon. It records version, sha256, approving run, candidate artifact, approval time, previous hash, and optional approval message.
- Optional multi-approver policy lives at `config/evolution/role-skills/approval-policy.json`; copy `config/evolution/role-skills/approval-policy.example.json` and set `requiredApprovals` plus allowed `approvers`.
